# Трекер сну

Android-застосунок, у якому щоранку за кілька секунд записуєте, скільки спали, а він показує статистику за тиждень, місяць і рік. Інтерфейс — у дусі iOS, світла й темна теми, усе українською. Дані зберігаються **лише на телефоні** й нікуди не надсилаються.

Зроблено на Expo SDK 57 (React Native + TypeScript). APK збирається безкоштовно в хмарі Expo — комп’ютер із Android Studio не потрібен.

## Що вміє зараз

- **Запис сну.** Години й хвилини: барабани, як у iOS, або швидкі кнопки. За сьогодні, вчора чи будь-яку іншу дату. Дата запису — день пробудження.
- **Сьогодні.** Кільце-місяць із прогресом до цілі, серія днів поспіль, середній сон за 7 днів, мініграфік, порада чи факт, що змінюється **кожні 2 години**.
- **Статистика за тиждень, місяць і рік** з перемиканням між періодами:
  середній і «типовий» (медіана) сон, найдовша й найкоротша ніч, частка ночей, коли досягнуто ціль, недосип до цілі, регулярність режиму, розподіл **«скільки ночей по годинах»** (менше 4, 4–5, 5–6, … 10+), середнє за днями тижня, порівняння з попереднім періодом і короткі висновки.
- **Історія.** Усі записи за місяцями, правка й видалення.
- **Параметри.** Ціль сну, початок тижня, тема, поради вкл/викл, резервна копія текстом (надіслати, скопіювати, відновити), демонстраційні дані «на пробу», видалення всіх даних.

**Закладено на майбутнє** (код уже є, вмикається перемикачем — див. [docs/ROADMAP.md](docs/ROADMAP.md)):

- **Дані з годинника** через Health Connect з перемикачем «Мої записи / Годинник» у статистиці. Чи вміє ваш Da Fit передавати сон у Health Connect, треба перевірити на телефоні — як, описано в [ROADMAP](docs/ROADMAP.md#головне-питання-на-яке-поки-немає-відповіді).
- **Поради й факти з інтернету**: тисячі текстів можна підвантажувати з простого JSON-файлу, а вбудовані (39 штук) лишаються запасними.

## Як отримати APK — коротко

Повна покрокова інструкція — [docs/APK.md](docs/APK.md). Потрібні: Node.js 22.13+ і безкоштовний акаунт на [expo.dev](https://expo.dev).

```bash
npm install                     # залежності
npx expo install --fix          # узгодити версії пакетів із Expo SDK 57
npx expo-doctor                 # перевірка проєкту
npm install --global eas-cli    # хмарний збирач
eas login                       # вхід в акаунт Expo
eas build --platform android --profile preview   # збірка APK (10–60 хв)
```

Далі: відкрийте посилання зі збірки на телефоні → завантажте `.apk` → дозвольте встановлення невідомих програм → «Встановити».

> Перед першою збіркою замініть `android.package` в `app.json` (за замовчуванням `com.sleeptracker.app`) на власний, наприклад `com.ваш-нік.sleeptracker`: пізніше змінити його без втрати даних неможливо.

## Для розробки

```bash
npm test               # 94 автотести логіки й бази даних (потрібен Node 22.13+)
npm run typecheck      # суворі типи TypeScript
npm run doctor         # npx expo-doctor
```

Щоб бачити зміни на телефоні миттєво, зберіть «development build» і запустіть `npx expo start --dev-client` — див. [docs/APK.md](docs/APK.md#швидка-розробка-з-перезавантаженням-на-льоту). Готовий Expo Go не використовується: він не підтримує нативні модулі (потрібні для годинника).

## Структура проєкту

```
App.tsx, index.ts          вхід: шрифти, заставка, база даних, екран помилки запуску
app.json, eas.json         налаштування застосунку й збірки APK
assets/                    іконка, заставка, шрифт Inter
docs/                      інструкції
src/
  config/features.ts       перемикачі майбутніх можливостей (годинник, поради з інтернету)
  domain/                  чиста логіка: дати, формати, статистика, серії, копії, налаштування
  data/                    сховище записів: SQLite (телефон) і пам’ять (тести), міграції
  integrations/            зовнішні джерела сну (годинник / Health Connect — заготовка)
  tips/                    поради й факти: вбудовані, інтернет-стрічка, ротація кожні 2 години
  state/                   контекст застосунку й підготовка даних для екранів
  theme/                   кольори (світла/темна), типографіка, розміри
  ui/                      компоненти в стилі iOS, графіки на SVG
  screens/                 Сьогодні, Статистика, Історія, Параметри, аркуш запису
tests/                     автотести
tools/make_icons.py        генератор іконок
```

## Що перевірено, а що ні

- ✅ 94 автотести: дати, статистика, формати, копії, база даних (на справжньому SQLite), синхронізація, ротація порад.
- ✅ Суворі типи TypeScript, 17 сценаріїв в інтерфейсі в браузерному стенді, що імітує Android (запис, правка, статистика, копії, темна тема, вузькі екрани, помилка бази тощо).
- ⚠️ **Не запускалося на справжньому телефоні** і зі справжніми пакетами Expo / React Native: у середовищі, де створювався проєкт, їх встановити не вдалося. Тому перша збірка може потребувати дрібних виправлень — діагностика в [docs/APK.md](docs/APK.md#якщо-щось-пішло-не-так).
- ⚠️ **Годинник** ще не підключено: код-заготовка є, але реальне підключення потребує перевірки на вашому телефоні.
