# Тестовий стенд у браузері

Збирає застосунок разом з імітацією react-native на DOM (`shim/`) і проганяє сценарії в Chromium через Playwright.
Не замінює перевірку на телефоні, але ловить помилки в жестах, анімаціях і розкладці.

- `build.sh` — збирає `dist/app.js` (потрібні esbuild і Playwright з `/opt/npm-tools`).
- `scenarios.cjs` — вкладки, лінза, гортання, перетягування.
- `scenarios2.cjs` — «Рік у крапках», аркуш запису, порада «Ще одна», демо-дані.
- `demo-check.cjs` — видалення демо-даних.

Запуск: `bash harness/build.sh && node harness/scenarios.cjs`. Шляхи в скриптах абсолютні, їх треба поправити під своє середовище.
